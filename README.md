## 提示词工程 （Prompt Engineering）

### 什么是提示词（Prompt）

- Prompt 并不是通过代码式的命令，而是通过自然语言描述告诉模型
- 告诉模型做什么、怎么做、做成什么样的指令
- 提示词的设计质量决定了模型的输出质量，提示词越详细、具体，模型输出的回答就会越准确越有用

### 如何设计提示词

- 为模型指定明确的角色
- 清晰具体的任务指令
- 结构化提示词
